# 桌宠美术素材清单（照这个做就能换皮套）

> 适用：`surfpet` 0.2.3（schema 2 皮肤规范）
> 数据来源：官方皮肤 `feiyu-01` 的 19 层**实测包围盒**，不是估算值。
> 你只要按下面的尺寸和位置出图，丢进 `surfpet\app\skins\<id>\` 就能用。

---

## 一、先定画布（这条错了后面全歪）

| 画布 | 适合 | `display.scale` | 角色实测占位 |
| --- | --- | --- | --- |
| **1024 × 1024** | 半身近景（推荐入门） | `0.44` | 宽 66%、高 90% |
| 1280 × 1280 | 全身站姿 | `0.32` | 宽 58%、高 97% |

四条硬规则：

1. **正方形**，所有层尺寸完全一致
2. **PNG-32 透明底**，不要白底、不要投影、不要地面
3. **禁止逐层裁边** —— 每张都是整块画布，角色在画布里的位置固定不动。
   这是新手最容易犯的错：把每层的透明边裁掉，结果眼睛跑到脸上别的地方去了
4. 角色**底部贴画布底边**（留 0~24px），头顶不要顶到上沿（官方是 y=103 起）

## 二、分三档做，别一上来就 19 张

| 档位 | 张数 | 能实现的效果 | 怎么做 |
| --- | --- | --- | --- |
| **A 最小** | 1 | 呼吸、摇摆、拖拽、摸头、跳跃、贴边吸附 | 一张整身图，`role` 写 `body`，用 `tools\MakeSkin` 一条命令生成 |
| **B 标准** | 9~11 | A + **眨眼** + **视线跟随** + **说话嘴型** | 眼白×2、虹膜×2、睫毛×2、嘴×1、脸×1、身体×1~2 |
| **C 完整** | 19~21 | B + 前后发独立摆动、尾巴摇、腿脚、头饰分层 | 下面完整表 |

**建议路径**：先做 A 档（今天就能换），跑通了再补 B 档的眼睛。

## 四、眼睛到底画在哪（你专门问的）

### 4.1 实测坐标

| 项 | 画布坐标 | 占画布 |
| --- | --- | --- |
| 左眼白 bbox | (625,382) – (687,438) | 眼心 **(656, 410)** = 64%, 40% |
| 右眼白 bbox | (482,344) – (554,398) | 眼心 **(518, 371)** = 51%, 36% |
| 左虹膜 bbox | (625,387) – (671,435) | 46×48 |
| 右虹膜 bbox | (499,349) – (549,399) | 50×50 |
| 左睫毛 bbox | (620,360) – (705,437) | 85×77 |
| 右睫毛 bbox | (461,328) – (573,369) | 112×41 |

### 4.2 换算成通用规则（换画布也能用）

- **两眼中心间距** ≈ 画布宽的 **13.5%**（138px / 1024）
- **眼白高度** ≈ 画布高的 **5.4%**（55px）
- **两眼总跨度**（含睫毛）≈ 画布宽的 **20%**
- 右眼比左眼**高约 36px、靠左 138px**（因为头微微侧了一点，不是严格对称）
- 眼睛的垂直位置在画布 **36% ~ 40%** 高度，脸的范围是 y 186~531（18%~52%）

### 4.3 三层怎么套（这个决定了眨眼好不好看）

```
睫毛   ← 最上层，比眼白大一圈，向上多出 20~30%（闭眼就是让它往下移）
虹膜   ← 盖在眼白上，占眼白的 60%~80%，略偏内上方
眼白   ← 最底层
```

闭眼**不需要画闭眼图**：程序把睫毛往下平移 `blinkLash` 这么多像素，
眼白和虹膜同时淡出，就成了一条闭眼线。

```jsonc
"blinkLash": { "l": [0, 10], "r": [0, 12] }   // 官方 feiyu-01：右眼多移 2px
```

> 如果睫毛形状很薄，闭眼会「闭不严」。做法：把睫毛画厚一点，
> 或者把 `blinkLash` 的 y 值调大（feiyu-05 用了 **55px**，因为它眼睛很大）。

### 4.4 两个锚点

```jsonc
"eyeCenters": { "l": [648, 411], "r": [524, 374] },   // 视线跟随的旋转中心，≈ 眼白 bbox 中心
"gazeCenter": [586, 392]                              // = 两个 eyeCenters 的平均点，不用单独量
```

`gazeCenter` 就是 `((648+524)/2, (411+374)/2) = (586, 392.5)` —— 实测完全对得上，你按平均值填即可。

`motion.gazeMax: [6, 4.5]` 是虹膜最大位移（画布像素）。**别调太大**：
官方评估「虹膜 ±3px 内自然，再大就出眼白」。

## 五、嘴

实测：`bbox (551,442,56,32)`，嘴心 **(579, 458)** = 56.5%, 44.7%。

`mouthPivot` 官方是 `[579, 442]`（嘴的上缘，不是中心），缩放以它为轴。

三种方案，按你原图长什么样选：

| 原图是 | `mouth.rest` | 说话时怎么做 | 需要额外素材 |
| --- | --- | --- | --- |
| 闭合的 w 型猫嘴 | `closed` | 把闭嘴边整层收掉（`hideBase:true`），淡入画好的张嘴 | `11_mouth_open.png` |
| 张开的笑 | `open` | 把嘴层**纵向压扁**来闭嘴 | 无 |
| 闭合小圆点 | `closed` | 淡入小圆嘴 + 用补丁擦掉原点 | `12_mouth_open.png` + `_cover` |

```jsonc
// 方案一（w 嘴，官方 feiyu-01）
"mouth": {
  "rest": "closed",
  "open": "art/11_mouth_open.png",
  "openPivot": [579, 467],
  "openOffset": [-3, -4],
  "openRotation": 15,
  "hideBase": true
}
```

张嘴素材要**和皮肤同画布、同位置、透明底**，只画口腔和舌头。

## 六、其余锚点（不填有默认值，但会不准）

| 字段 | 官方值 | 含义 | 怎么量 |
| --- | --- | --- | --- |
| `headPivot` | `[556, 512]` | 头部旋转/位移的中心 | 脖子根部，下巴下方一点 |
| `backHairPivot` | `[512, 320]` | 后发摆动轴 | 后发 bbox 上缘中部 |
| `mouthPivot` | `[579, 442]` | 嘴缩放轴 | 嘴的上唇线中点 |
| `motion.breath` | `0.011` | 呼吸时纵向缩放 | 1.1% 就够了 |
| `motion.sway` | `0.008` | 整体左右轻晃 | 0.8% |
| `motion.headTurn` | `10` | 头部左右平移像素 | 10~16 自然，>40 会露馅（发/脸不联动） |
| `motion.gazeMax` | `[6, 4.5]` | 虹膜最大位移 | 3px 左右最自然 |

`headTurn` 的教训（官方原话）：「脸组平移 ±16px 无破绽；±40px 开始露馅」。

## 七、命中区（`interaction.regions`）

坐标是**画布坐标**，不是屏幕坐标。数组越靠前优先级越高。

```jsonc
"regions": [
  { "id": "head", "gesture": "pat",  "cursor": "pointer",
    "shape": { "type": "ellipse", "cx": 596, "cy": 320, "rx": 200, "ry": 200 },
    "hoverCloseEyes": true },
  { "id": "body", "gesture": "poke", "cursor": "pointer",
    "shape": { "type": "rect", "x": 240, "y": 480, "w": 560, "h": 544 } }
]
```

- `pat` = 摸摸（头顶那圈），`poke` = 戳一下
- 官方头部椭圆：中心 `(596, 320)`、半径 `200 × 200` —— 大致覆盖头饰+脸
- 想要「点某个部位响个音效」，加 `"sound": "potHit"` + `interaction.sounds` 映射

## 八、AI 出图的可操作流程

### 8.0 出图提示词（直接复制，把花括号换成你的角色设定）

> ⚠️ 提示词 ②~⑥ 产出的只是**局部补丁**，不能替代「从整图切层」。
> 主路径永远是 ①：先出整身图，再从它切。局部补丁只用来补 AI 切不干净的部位（尤其眼睛）。

**① 整身基准图（最重要，后面全部从这张切）**

```
动漫风格立绘，{发色+发型}，{瞳色}眼睛，{服装描述}，正面视角，
半身（到腰），双手自然下垂，表情平静，双眼睁开直视前方，
纯白色背景，无阴影，无地面，无文字，无水印，
正方形构图，1024×1024，线条干净，高清
```

> 要**全身**就把「半身（到腰）」换成「全身站立，双脚可见」。
> 要**3/4 侧脸**就在开头加「3/4 侧面」。别同时要多个视角。

**② 眼白（左右各一张）**

```
单独一只眼睛的眼白部分（只有白色巩膜，不含虹膜、不含睫毛、不含眉毛），
透明背景，{左/右}眼，正面视角，边缘清晰，1024×1024
```

**③ 虹膜（左右各一张）**

```
单独一只眼睛的虹膜（{瞳色}，带高光和瞳孔），圆形，透明背景，
{左/右}眼，正面视角，1024×1024
```

**④ 睫毛 / 眼线（左右各一张）**

```
单独一只眼睛的睫毛和上眼线（深色描边），不含眼白、不含虹膜，
透明背景，{左/右}眼，正面视角，1024×1024
```

**⑤ 嘴（闭合、张开各一张）**

```
单独一张嘴，{闭合：小巧的微笑唇 / 张开：口腔和舌头清晰可见}，
透明背景，正面视角，只画嘴部，1024×1024
```

**⑥ 脸部（建议抠图，不建议让 AI 重画）**

用整图 ① 抠掉眼睛、嘴、眉毛、头发，剩下的就是 `face` 层。
让 AI 单独画一张「脸」几乎必然和原图对不上，别走这条路。

### 8.1 工作流

1. **先出一张完整角色**（不要一次要 19 张）。要求：正面或 3/4 侧、全身或半身、**纯色/透明背景**、无地面阴影、双手可见、表情平静。
2. **用同一张图做分层**。这是唯一可靠的路径：
   - 用抠图/蒙版工具（PS、Krita、Photopea 都行）在原图上分别导出「只有后发」「只有脸」「只有左眼白」……
   - **绝对不要**让 AI 分别生成 19 张——每张的角色位置、比例、脸型都会不一样，叠起来就是错位的。
3. **眼睛值得手工修**。AI 出的眼白/虹膜边缘通常糊，但这三层会被程序移动，边界一糊就会露出破绽。
4. **脸要挖空**。眼窝和嘴的位置在 `09_face.png` 里必须挖掉（透明），否则会挡住下面的眼睛和嘴。
5. **尺寸**：AI 直接出 1024×1024 最好；出了 1024×1536 也行，最后统一缩放贴到 1024² 画布再分层导出。
6. **提示词模板**（供参考）：
   > 正面半身立绘，动漫风格，成年女性，蓝色长裙，双手自然下垂，纯白色背景，无阴影，无文字，全身完整，眼睛清晰，正面视角，对称构图
7. **每出一层都跑一次核对**（见下一节）。

## 九、验收：一条命令查所有层的位置

```powershell
dotnet run --project tools\MakeSkin -- --report surfpet\app\skins\<你的id>
```

输出示例（官方 feiyu-01）：

```
layer           role          group  file                    w     h     bx   by   bw   bh
eye.white.l     eye.white.l   head   12_eyewhite-l.png       1024  1024  625  382  62   56
...
# UNION  x=171 y=103 w=681 h=921  占画布 66.5% x 89.9%
```

合格标准：

- [ ] 每层都是 `1024 × 1024`（或你选的画布尺寸），格式 PNG-32
- [ ] UNION 宽占 **58% ~ 70%**、高占 **88% ~ 98%**（太小说明角色太小，太大说明贴边了）
- [ ] UNION 的 `y + h` ≈ 画布高度（底部贴边，差 0~24px）
- [ ] 眼白 bbox 完全包含虹膜 bbox
- [ ] 睫毛 bbox 比眼白 bbox 大，且上缘更高
- [ ] 各层 `bx/by` 之间的关系合理（前发在脸之上、后发在最底）

## 十一、最小可用捷径

不想折腾分层？就做 A 档：

```powershell
dotnet run --project tools\MakeSkin -- `
  --src D:\我的图\角色.png `
  --out surfpet\app\skins\my-01 --id my-01 --name "我的角色"
```

它会自动算画布对齐、包围盒、缩放、命中区，生成单层皮肤（`role: body`）。
有呼吸/摇摆/拖拽/摸头/跳跃；**没有**眨眼、视线跟随、嘴型 —— 那些必须分层。
