# 小肥鱼桌宠 · 换皮套指南

这是从 [Mieksido/surfpet](https://github.com/Mieksido/surfpet) 的 Release（`pet-pack.zip` v0.2.3）
解出来的桌宠，加上 Electron v45.2.3 运行时。**代码 MIT**。

```
surfpet/
  runtime/          Electron 运行时（238 MB 的 electron.exe + 依赖）
  app/              桌宠本体（dist/ 已构建的 JS + skins/ 皮肤 + assets/）
  启动桌宠.cmd       双击启动
```

## 一、启动

双击 **`启动桌宠.cmd`**。

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 拖着走，松手会吸附到边缘 |
| 右键 | 摸摸头 / 戳一下 / **穿什么呢** / 大小 / 回右下角 / 隐藏 / 退出 |
| 托盘图标 | 同一套菜单 |
| 鼠标停在身上 | 会闭眼、虹膜跟着你的鼠标动 |

透明区域点得穿，不挡后面的窗口。

> 这个包**没连 SurfCore**，所以没有文本/语音对话，会提示「surfcore offline」。
> 想要对话/记忆/主动搭话，得装 SurfCore 插件，再把它的「设置 → 桌宠」指向本目录的
> `runtime\electron.exe`，安装包地址填这个 `app` 目录打包的 zip。

## 三、换一套自己的皮套

### 3.1 最快：一张图变一套皮套

```powershell
dotnet run --project tools\MakeSkin -- `
  --src  D:\我的图\角色.png `
  --out  surfpet\app\skins\my-01 `
  --id   my-01 `
  --name "我的角色"
```

它会自动算好画布对齐、包围盒、缩放、命中区，生成符合规范的 `manifest.json` +
`art/01_body.png` + `preview.png`。重启桌宠，右键就能选到。

**代价**（重要）：单层皮肤只有**呼吸 / 摇摆 / 拖拽 / 摸头 / 跳跃**，
没有眨眼、没有视线跟随、没有说话嘴型——因为那些需要把眼睛、嘴、头发拆成独立图层。

### 3.2 完整效果：自己拆层

皮套 = 一个目录，纯数据，不会被当代码执行：

```
skins/<id>/
  manifest.json      必需
  art/*.png          必需：所有层同画布、同位置、透明底
  preview.png        可选：128px 缩略图
  persona.md         可选：人设
```

`manifest.json` 的关键字段：

```jsonc
{
  "schema": 2,
  "id": "my-01",
  "name": "我的角色",
  "rig": "layered",
  "canvas": { "w": 1024, "h": 1024 },
  "display": { "scale": 0.44 },            // 画布 → 屏幕的缩放
  "hitbox": { "x": 205, "y": 95, "w": 630, "h": 929 },   // 粗命中矩形
  "rigOptions": {                          // 全部可省略，省略就用默认锚点
    "headPivot": [556, 512],
    "mouthPivot": [579, 442],
    "gazeCenter": [586, 392],
    "eyeCenters": { "l": [648, 411], "r": [524, 374] },
    "motion": { "breath": 0.011, "sway": 0.008, "headTurn": 10, "gazeMax": [6, 4.5] },
    "blinkLash": { "l": [0, 10], "r": [0, 12] },          // 闭眼时睫毛下移多少
    "mouth": { "rest": "closed", "open": "art/11_mouth_open.png", "openPivot": [579, 467] }
  },
  "interaction": {
    "regions": [                           // 语义区：决定摸头/戳身体的反应
      { "id": "head", "gesture": "pat", "shape": { "type": "ellipse", "cx": 596, "cy": 320, "rx": 200, "ry": 200 } },
      { "id": "body", "gesture": "poke", "shape": { "type": "rect", "x": 240, "y": 480, "w": 560, "h": 544 } }
    ],
    "menu": ["pat", "poke", "hop", "blink", "talk", "separator", "recenter", "hide", "quit"]
  },
  "layers": [                              // 从下往上叠
    { "id": "hair.back", "file": "art/02_back_hair.png", "group": "body", "role": "hair.back" },
    { "id": "face",      "file": "art/09_face.png",      "group": "head", "role": "face" },
    { "id": "eye.white.l","file": "art/12_eyewhite-l.png","group": "head", "role": "eye.white.l" }
  ]
}
```

- `group`：`head` 跟头部动，`body` 跟身体动
- `role` 是行为钩子，常用的：
  `eye.white.l/r`、`eye.iris.l/r`（视线跟随）、`eye.lash.l/r`（眨眼）、`brow.l/r`、
  `mouth`、`face`、`nose`、`headwear`、`hair.front`、`hair.back`、`tail`
- 完整规范见 `.upstream/surfpet/docs/SKIN-SPEC.md`
- 命中遮罩不用自己做，运行时会由所有层的 alpha 合成 256×256

美术要求：**所有层同一画布、同一位置**（不要逐层裁边），透明底，角色底部贴画布底边。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 双击没反应 | 用 `启动桌宠.cmd`；或命令行 `runtime\electron.exe app --no-sandbox` 看报错 |
| 白屏 / 起不来 | 加上 `--no-sandbox`（启动脚本已带） |
| 换了皮肤没生效 | 必须重启桌宠；新皮肤目录名要和 `manifest.json` 的 `id` 一致 |
| 皮肤选了没图 | 看 `manifest.json` 里 `layers[].file` 的路径是否正确、PNG 是否真透明 |
