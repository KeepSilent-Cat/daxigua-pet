## 二、素材规格（C1 整身帧序列）

### 2.1 画布与对齐（最重要，错在这里会全废）

| 项 | 要求 |
|---|---|
| 画布 | **1280 × 1280**，和现有所有图层完全一致 |
| 位置 | **不能重新构图**。每一帧的脚底、头顶、身体中线必须和 `02_body.png` 对得上 |
| 背景 | 透明（PNG-24 带 alpha） |
| 首帧基准 | 建议**先导出当前 `02_body.png` 当底**，在这张上改腿，保证零位移 |

> 判断有没有对歪：把新帧和 `01_hair.back.png` 叠一起，头的位置应该正好落在后发里。

### 2.2 帧数与命名

最少 **4 帧**，推荐 **8 帧**（顺滑度差一倍，素材量翻倍）。

```
art\walk\
  walk_01_contact.png     左脚着地、右脚在后（接触）
  walk_02_down.png        重心最低、身体最沉（下沉）
  walk_03_pass.png        后脚过中线（通过）
  walk_04_up.png          重心最高、身体抬起（上升）
  walk_05_contact.png     右脚着地（与 01 镜像相位）
  walk_06_down.png
  walk_07_pass.png
  walk_08_up.png
```

4 帧版只做 `01/02/03/04`，第 5~8 帧用镜像或重复 1~4。

### 2.3 每一帧要画什么

**C1 整身帧 = 完整的角色（含头、头发、衣服、腿脚），但不含五官细节的动画**
（眼睛、嘴、眉毛可以画成"睁眼闭嘴"的中性状态，因为行走时不播分层）

| 必须有 | 说明 |
|---|---|
| 身体 + 四肢 + 衣服 | 和现有立绘同一个角色、同一套颜色 |
| 腿和脚 | **这是唯一需要新画的部分**：迈步时前后腿分开、膝盖弯曲、脚掌离地/落地 |
| 头发 | 后发可以画得略微飘起（走路的惯性），但**不要超出画布** |

| 不需要 | 说明 |
|---|---|
| 眼睛/嘴的多种状态 | 单独一张中性脸就够 |
| 耳朵抽动 | 行走时不播 |

### 2.4 循环要点

1. **首尾要能接上**：`walk_08` 的结束姿态 = `walk_01` 的起始姿态（否则循环会"闪一下"）
2. **重心轨迹**：接触(中) → 下沉(低) → 通过(中) → 上升(高)，一个循环有 **两次**这样的起伏（左右腿各一次）
3. **脚不要打滑**：着地的那只脚在这几帧里位置要基本不动（这是判断帧是否合格最直观的标准）

### 2.5 朝向与镜像

- 单片序列默认朝**画面右**走
- 朝左时用镜像（`scaleX = -1`）
- ⚠️ 镜像会翻转这些**不对称细节**，做之前先确认能不能接受：
  - `21_corner.r` / `22_corner.l`（左右角形状不同）
  - `23_headwear`（只在一侧的头饰）
  - 眼睛高光、单侧刘海
- **不接受镜像** → 需要左右各画一套（素材量 ×2）

### 2.6 体积预估

| 项 | 数值 |
|---|---|
| 单帧 | 约 300~500 KB（1280² 带 alpha） |
| 8 帧 | 约 **3~4 MB** |
| 皮套总体积 | 2.2 MB → **约 6 MB** |
| 安装包 | 206 MB → 约 210 MB（影响可忽略） |

## 三、代码要改哪里（我来做）

### 3.1 manifest 新增字段

```jsonc
{
  "walkFrames": {
    "dir": "art/walk",
    "frames": ["walk_01_contact.png", "walk_02_down.png", "walk_03_pass.png", "walk_04_up.png",
               "walk_05_contact.png", "walk_06_down.png", "walk_07_pass.png", "walk_08_up.png"],
    "fps": 10,              // 每秒播几帧（8 帧 10fps = 0.8 秒一个循环）
    "stridePx": 48,         // 一个循环位移多少像素（决定步幅，要和窗口速度匹配）
    "mirrorForLeft": true   // 朝左走时是否镜像
  }
}
```

`stridePx` 很关键：**窗口移动速度要和它匹配**，否则会"脚打滑"。
例：`stridePx = 48`、`fps = 10` → 一个循环 0.8 秒走 48px → 速度 = 60 px/s。
现在走动的速度是 72 px/s，所以要么把 `stridePx` 调到 58，要么速度降到 60。

### 3.2 renderer.js 改动（约 60 行）

1. **加载帧序列**：`loadWalkFrames()` 把 8 张图加载成 `this.walkSprites[]`
2. **增加一个 sprite**：`this.walkSprite`，加到 `this.body` 里，`visible = false`
3. **行走时**（`this.walking`）：
   - 隐藏所有分层（`this.head.visible = false`、`this.body` 里除 walkSprite 外全隐藏，或用一个容器分组）
   - 显示 `walkSprite`，按 `walkPhase` 取帧：`idx = floor(phase * frames.length) % frames.length`
   - `walkSprite.scale.x = dir < 0 && mirror ? -1 : 1`
4. **停下时**：恢复分层显示、隐藏 walkSprite

实现时要注意：现在的分层是直接 addChild 到 `this.body` / `this.head` 的，没有分组，所以"一键隐藏"需要我加一个容器层（`this.rigRoot`），把现有层都挂进去。这是**唯一有返工风险**的地方，我会在改之前先备份。

### 3.3 main.js 改动

**不需要改**。走动逻辑（抽卡、缓入缓出、边界折返、托盘开关）已经做好，帧序列只是渲染层的事。

### 3.4 如果以后升级到 C2（身体帧 + 头分层）

额外要做：
- 每帧记录一个"身体起伏值"，头部按这个值同步位移（我可以在渲染时分析帧里的头顶高度自动算）
- 头、发、眼、嘴、耳继续用现有分层
- 素材上只需画"脖子以下 + 手臂"
